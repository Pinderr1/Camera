## Alert Severity

Low-severity check:

- Bathroom overstay beyond normal range.
- Bed exit with delayed return but no fall-like signal.
- Unusual inactivity compared with normal routine.
- Sensor uncertainty during a non-urgent state.

Urgent caregiver check:

- Possible fall plus stillness.
- Floor-level posture outside bed plus no movement.
- Bed exit/no return plus route sensors quiet for too long.
- Bathroom overstay plus no motion or failed local check-in.
- Manual help button pressed.
- System cannot see/sense a high-risk active trip.

## Response Ladder

1. Local soft check asks whether she is okay, if this is acceptable to her.
2. Primary caregiver receives notice with state, duration, zone, and reason codes.
3. Primary caregiver acknowledges and checks by call, camera/pose summary, or in person.
4. Backup caregiver is contacted if the primary does not acknowledge in the configured window.
5. Emergency services are called by a human responder when the situation looks urgent or cannot be verified.

Do not enable automatic emergency calls until the family has tested the system, understands false alarms, and explicitly chooses a policy.

## What The Alert Message Should Include

- Current state.
- Severity.
- Last seen zone.
- How long the condition has persisted.
- Reason codes.
- Whether bed, bathroom, camera, and network sensors are healthy.
- Acknowledge button or reply option.
- Review outcome choices: real issue, helpful check, false alarm, nuisance alert, missed concern.

## After Every Alert

Record:

- Was she okay?
- Did anyone check?
- How long did acknowledgement take?
- Was the alert useful?
- Was it too early, too late, or wrong?
- Which threshold or sensor should change?

## Manual Safety Backups

Use at least one manual backup:

- Bedside help button.
- Bathroom/path help button.
- Pendant or watch if she will wear it.
- Phone reachable from bed.
- Voice assistant emergency/contact command if she can use it reliably.
