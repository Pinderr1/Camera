# Observation-Only Trial

Run observation-only before caregiver wakeups. The goal is to learn normal timing, blind spots, and nuisance patterns.

## Minimum Duration

- 7 nights before low-severity caregiver notifications.
- 14 nights preferred before urgent overnight wakeups.
- 30 nights before treating personal timing baselines as stable.

## Record Every Morning

- Bed exits.
- Bathroom enter and exit.
- Bed return.
- Long bathroom occupancy.
- Long out-of-bed unknown periods.
- Sensor dropouts.
- Manual help/cancel tests.
- False fall-like movement.
- Any missed concern that a caregiver noticed outside the system.

## Acceptance Before Notifications

- Normal bed-to-bathroom-to-bed transitions are understandable in logs.
- Critical sensor failures become `offline_or_blind`.
- No bathroom video is required.
- Low-severity nuisance candidates are below 1 per night.
- Urgent false-alert candidates are below 1 per week in review.
